## Puntos verificados contra la doc (todo coincide)

- `--max-turns`: "print mode only. No limit by default". `--max-budget-usd`: "Spend from subagents counts toward the cap. Spend can pass the cap, so leave headroom" (cli-reference).
- `-p` arranca en Manual desde v2.1.302, y lo que pide aprobación se niega y va a `permission_denials`. `dontAsk` es para CI cerrado. `--bare` no usa el login de suscripción (headless).
- `--tools` restringe y `--allowedTools` pre-aprueba: "To restrict which tools are available, use `--tools` instead" (cli-reference). Pasar el diff por stdin y el espacio antes de `*` en `Bash(git diff *)` (headless).
- Si no hay `structured_output` hay que chequear que exista (headless). `success` + `is_error` + `structured_output` (agent-sdk/structured-outputs). Draft-07 y `error_max_structured_output_retries` (ídem).
- GitHub Action v1: `claude_args`, `--comment` y `mcp__github_inline_comment__create_inline_comment` (github-actions). Code Review: "never approves or blocks" y `REVIEW.md` "from the base or default branch" (code-review).
- Skills: `context: fork`, `agent` con default `general-purpose`, `background` con default `true`, `model`/`effort` que se aplican al fork, Explore/Plan sin CLAUDE.md, la regla del `---` en la línea 1, "Despite the name…", y que `.claude/commands/` acepta los mismos campos salvo `name`/`paths`. `/subtask` existe (sub-agents → "Fork the current conversation").
- Fork mode activado por defecto y `CLAUDE_CODE_FORK_SUBAGENT=0` para poder esperar (sub-agents), que es lo que usa el lab 10.
- Permisos: deny → ask → allow. "If a tool is denied at any level, no other level can allow it". Alias de PowerShell canonicalizados. Un Read deny cubre `cat` en Bash pero no scripts. Un deny de Bash apaga la tool PowerShell (tools-reference). El sandbox no corre en Windows nativo (sandboxing). `onFailure: "block"` desde v2.1.295. Exit 0 no aprueba nada (hooks).
- Glob/Grep: en Windows vienen por defecto. Glob ordena por mtime con tope de 100. Grep respeta `.gitignore` (a un archivo ignorado se llega pasando la ruta) y por defecto devuelve `files_with_matches`. Read: 25.000 tokens / 256 KB, `PARTIAL view`, `allow_large` desde v2.1.296 (tools-reference).
- Citations + `output_config.format` → 400. La solución es "one line per field", y la doc avisa que un "only JSON" deja pocas citas. `context` vs `title` (citations). `AgentDefinition` no tiene campo de schema. El texto literal del subagente se pide en el prompt del `query()` principal (agent-sdk/subagents).
