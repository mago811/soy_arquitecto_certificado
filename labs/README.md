# Labs

Un archivo `.md` por lab, con instrucciones paso a paso. Se generan día a día en la Fase 2.

Convención: `day-XX-tema.md` (ej: `day-01-enforcement.md`).

Cada lab sigue el mismo formato:

1. **Objetivo** — qué principio del examen demuestra
2. **Setup** — qué necesitás tener a mano
3. **Pasos** — el coach escribe el código base, vos lo rompés y lo arreglás
4. **Qué tenías que ver** — el aprendizaje en una frase, estilo examen
